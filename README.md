# Balcão

Backend de uma loja online: catálogo, estoque, carrinho, pedidos e
pagamento simulado.

## Objetivo

Projeto de estudo para evoluir como engenheiro de software,
construído em fases: do monólito simples até testes automatizados, Docker,
CI/CD e observabilidade. A cada fase o sistema ganha complexidade real.

## Stack

TypeScript, Node.js, PostgreSQL, Docker.

## Como rodar

    npm install
    npm run dev

## Scripts

- `npm run dev`: executa em modo watch
- `npm run build`: compila para `dist/`
- `npm run typecheck`: verifica os tipos
- `npm run lint`: roda o ESLint
- `npm run format`: formata com Prettier
